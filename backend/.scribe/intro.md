# Introduction

API REST para gerenciamento de vendas, produtos e clientes do sistema CreditAll Challenge. Oferece funcionalidades completas de CRUD, controle de estoque, cálculo de descontos e gerenciamento de status de vendas.

<aside>
    <strong>Base URL</strong>: <code>http://localhost</code>
</aside>

    ## Bem-vindo à API CreditAll Challenge

    Esta documentação fornece todas as informações necessárias para integrar com nossa API REST.

    ### Principais Funcionalidades
    - **Gerenciamento de Produtos**: CRUD completo com upload de imagens e controle de estoque
    - **Gerenciamento de Clientes**: Cadastro com validação de CPF e histórico de compras
    - **Sistema de Vendas**: Criação de vendas com múltiplos itens, descontos e controle de status
    - **Autenticação Segura**: Sistema baseado em tokens Bearer (Laravel Sanctum)

    ### Características Técnicas
    - **Padrão REST**: Endpoints padronizados seguindo as melhores práticas
    - **Respostas JSON**: Todas as respostas em formato JSON com estrutura consistente
    - **Paginação**: Listagens com paginação automática para performance
    - **Validação**: Validação rigorosa de dados de entrada com mensagens em português
    - **Rate Limiting**: Controle de taxa de requisições para estabilidade
